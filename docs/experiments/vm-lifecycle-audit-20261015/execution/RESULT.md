## 本次已修复的主要问题

1. 下发尚未成功就绑定 Agent，导致失败配置也占着归属。
2. 旧会话或迟到回报覆盖新状态，导致停机后又显示可用。
3. 把 ADB、HDC 或查询失败当成实例不存在，导致错误释放或重建。
4. 用复用端口代替机器身份，导致别名、任务及状态串到另一台机器。
5. 首次创建失败回滚与旧实例重启失败混用，存在误删旧数据的风险。
6. 删除和换 Agent 等待旧宿主清理，使离线设备阻塞正常管理。
7. 换 Agent 撤旧建新及其异常分支不够原子，会覆盖并发请求的结果。
8. 扫描、就绪探针与生命周期操作相互阻塞，超时任务仍可能继续创建实例。
9. 运行、安装、观看及自动维护缺少共同的操作边界。
10. 鸿蒙镜像版本字段与系统版本字段混用，并对不同宿主做重复重探查。
11. 页面旧请求回写、轮询堆积与静默吞错，使实际失败难以识别。
12. Android 进程已退出后，端口 TIME_WAIT 被误判为仍有实例占用。
13. 鸿蒙退出确认失败缺少同步采样证据，事后只能看到已空闲，无法准确区分退出延迟、端口或查询耗时。
